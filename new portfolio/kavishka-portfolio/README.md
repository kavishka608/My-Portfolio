# Kavishka Dewduni Portfolio

A React portfolio tailored from Kavishka's CV. It uses the same broad section structure as the supplied reference: hero, about, skills, projects, timeline, contact, and footer.

## Run locally

```bash
cd kavishka-portfolio
npm install
npm start
```

The app opens at `http://localhost:3000`.

## Before publishing

- Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `client/src/components/Contact.jsx` with a Web3Forms access key to enable deliveries.
- Add an optional photo as `client/public/profile.jpg` and change the `Hero.jsx` image block if wanted.
- The downloadable CV is already included in `client/public/Kavishka-Dewduni-Resume.pdf`.
